# Smart Closet Final V2.4 - Global Removal Voice

추가 기능:
- 문이 열린 상태에서 Hall N이 OCCUPIED -> EMPTY로 바뀌면 기존 Slot 위치가 삭제됩니다.
- REMOVE_CONFIRMED 이벤트에 옷 번호/색상/종류/계절/추가정보를 기록합니다.
- 웹은 현재 화면과 무관하게 /api/events를 0.3초 간격으로 확인합니다.
- 옷을 꺼낸 이벤트가 생기면 예: "옷 3을 꺼냈습니다. 색상 검정색, 종류 반팔티, 계절 여름입니다."라고 즉시 음성 안내합니다.
- 동시에 화면 상단에 같은 내용을 5초간 표시합니다.
- 찾기 화면에 있었다면 현재 옷장 목록도 자동 새로고침합니다.

주의:
- 물리적 제거 판정은 기존 최종 코드처럼 문 센서가 OPEN인 세션에서 Hall OCCUPIED -> EMPTY 변화가 발생할 때 처리됩니다.
- 브라우저/OS 정책에 따라 페이지 최초 실행 직후 TTS가 제한될 수 있으므로 웹을 한 번 터치/클릭한 상태에서 사용하는 것을 권장합니다.
